# Contributing

Thanks for your interest in BUTT BOUNCE — Rooftop Rush!

1. Open the project in Godot 4.
2. Keep gameplay changes in `scripts/` and scene changes in `scenes/`.
3. Test the main scene with F5 before submitting changes.
4. Do not add models, music, sound effects, or textures unless their redistribution rights are clear. Record asset credits and license terms in `ASSET-LICENSING.md`.
5. Describe the change and how it was tested in your pull request.
