# BUTT BOUNCE — Character Pack 02–07

Six separate Godot-importable GLB character prototypes.

## Included
- `02_office_guy.glb` — The Office Guy
- `03_builder.glb` — The Builder
- `04_astronaut.glb` — The Astronaut
- `05_alien.glb` — The Alien
- `06_robot.glb` — The Robot
- `07_the_pro.glb` — The Pro

## Import
1. Extract this ZIP.
2. Copy all six `.glb` files into your Godot project's `characters/` folder.
3. Wait for Godot to import them.
4. Double-click each GLB in the FileSystem dock to preview it.
5. Drag each character into a temporary 3D scene to inspect it.

## Shared conventions
- Forward direction: +Z
- Up direction: +Y
- Approximate character height: 2.6 Godot units
- Neutral A-pose
- Named separate mesh parts and PBR-style materials

## Important limitations
These are stylized 3D prototype/blockout models made from separate mesh parts.
They are not yet rigged and contain no skeleton or animation clips. The geometry,
materials, scale and pose are designed as a consistent starting point, but we
must rig and test them in Godot before using them in the final character selector.
They are not final production-quality realistic human assets.
