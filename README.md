# BUTT BOUNCE — Rooftop Rush

A 3D rooftop parkour prototype built with **Godot 4** and GDScript.

Charge a bounce, launch yourself across rooftops, steer in mid-air, hit spring platforms, avoid hazards, and reach the goal.

## Project location

The Godot project is currently stored in:

## Getting started

1. Install Godot 4. The project was previously developed with Godot 4.7.2.
2. Download this repository as a ZIP or clone it.
3. Open **Godot Project Manager**.
4. Choose **Import** and select `BUTT-BOUNCE-Rooftop-Rush 2/project.godot`.
5. Open the project and allow Godot to import the 3D and audio assets.
6. Press **F5** to run the configured main scene.

## Controls

| Input | Action |
|---|---|
| W / A / S / D or arrow keys | Move and steer |
| Hold Space | Charge a bounce while grounded |
| Release Space | Launch the bounce |
| R | Restart / respawn |
